# World 3 No Level Cap

In World 3, no recruited character has a level cap, as Rance has none.
<img width="1024" height="768" alt="image" src="https://github.com/user-attachments/assets/5a3d7602-d3f0-4245-b222-78267db327e1" />

## What it changes

While a save is in World 3:

- **No cap.** Every recruited character, those recruited later too, gains EXP and levels past their
  cap, up to Rance's 999. The fight's result no longer marks them at the talent limit, and the
  reserve's free levels go on too.
- **∞ on the cards and the status page**, as Rance's.
- **Athena 2.0** stays at LV 1, as the game keeps her.
- **Forbidden Talents** and the game's other cap raises (the Morurun at the cap, skills that set a
  cap) still raise the character's own cap, for World 1 and 2.

Back in World 1 or 2 (Alice can take you there), the game's caps hold again: a character over theirs
keeps the level and gains no EXP until the cap is raised, as in the game.

EXP not given at the cap before the mod was installed is not given back. The bar fills from the next
fight.

## Keys and settings

- **Config → Mods → World 3 No Level Cap:** the box **No level cap in World 3**, on at first, for
  the loaded save only. With it off, the game's caps hold in World 3 too.

## Saves

Nothing is written into the game's save: the caps there are the game's. The box stays in
`RanceQuestMagnum_NNN.rqmod.json` beside each save; the game ignores the file. Remove the mod and the
game's caps hold again; the levels gained stay.

## Install

Needs [RQ MOD](https://github.com/RQ-Modding/RQ-Mod) with loader **2.56.1** or newer. Extract the
release zip into the game's `mods` folder, so that you have `mods/world3-no-cap/mod.json`.
